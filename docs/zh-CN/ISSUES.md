# 议题

创建议题前，先查看现有议题。如果已有相同问题，请在那里补充有用的信息。

## 创建议题

报告缺陷时，请说明预期行为、实际结果和复现方法，附上模组版本和 Minecraft 环境，并尽量提供相关日志。分享前，先删去日志中的敏感信息。

提出新功能或改进建议时，请说明遇到的问题和希望达到的效果，可以附上简短示例。也欢迎提问或讨论初步想法。

## 初步评估

调查议题时，维护者可以添加以下标签：https://github.com/12src/12pit/labels/needs%20triage、https://github.com/12src/12pit/labels/needs%20info 或 https://github.com/12src/12pit/labels/needs%20reproduction。

需要先做产品或技术决策时，使用 https://github.com/12src/12pit/labels/needs%20decision 标签。讨论使用 https://github.com/12src/12pit/labels/discussion 标签，提问使用 https://github.com/12src/12pit/labels/question 标签。https://github.com/12src/12pit/labels/invalid 标签用于基于错误假设或与项目无关的议题。

问题可以复现，或请求已被接受时，添加 https://github.com/12src/12pit/labels/confirmed 标签，然后按类型、领域、优先级和环境分类。

多数议题会在相关拉取请求合并后以 completed 状态关闭。部分议题在问题得到解答或讨论结束后关闭。其他关闭原因使用以下标签：https://github.com/12src/12pit/labels/duplicate、https://github.com/12src/12pit/labels/cannot%20reproduce、https://github.com/12src/12pit/labels/upstream 或 https://github.com/12src/12pit/labels/wontfix。

## 标签

新功能和改进建议使用 https://github.com/12src/12pit/labels/feature 或 https://github.com/12src/12pit/labels/enhancement 标签。

缺陷和各类故障使用 https://github.com/12src/12pit/labels/bug、https://github.com/12src/12pit/labels/crash、https://github.com/12src/12pit/labels/regression、https://github.com/12src/12pit/labels/compatibility 或 https://github.com/12src/12pit/labels/performance 标签。

涉及破坏性变更时，可以添加 https://github.com/12src/12pit/labels/breaking%20change 标签。其他维护工作使用 https://github.com/12src/12pit/labels/documentation、https://github.com/12src/12pit/labels/refactor、https://github.com/12src/12pit/labels/chore 或 https://github.com/12src/12pit/labels/clean 标签。

领域标签说明议题涉及项目的哪些部分：https://github.com/12src/12pit/labels/domain%3A%20CI、https://github.com/12src/12pit/labels/domain%3A%20build、https://github.com/12src/12pit/labels/domain%3A%20dependencies、https://github.com/12src/12pit/labels/domain%3A%20release、https://github.com/12src/12pit/labels/domain%3A%20testing、https://github.com/12src/12pit/labels/domain%3A%20architecture、https://github.com/12src/12pit/labels/domain%3A%20tooling、https://github.com/12src/12pit/labels/domain%3A%20localization、https://github.com/12src/12pit/labels/domain%3A%20licensing、https://github.com/12src/12pit/labels/domain%3A%20governance 和 https://github.com/12src/12pit/labels/domain%3A%20UI%2FUX。

优先级标签说明工作的紧迫程度：https://github.com/12src/12pit/labels/priority%3A%20P0、https://github.com/12src/12pit/labels/priority%3A%20P1、https://github.com/12src/12pit/labels/priority%3A%20P2 和 https://github.com/12src/12pit/labels/priority%3A%20P3。

环境标签说明问题出现的环境：https://github.com/12src/12pit/labels/env%3A%20Windows、https://github.com/12src/12pit/labels/env%3A%20Linux、https://github.com/12src/12pit/labels/env%3A%20macOS、https://github.com/12src/12pit/labels/env%3A%20mod%20conflict 和 https://github.com/12src/12pit/labels/env%3A%20server-specific。

议题还可以添加 https://github.com/12src/12pit/labels/blocked 或 https://github.com/12src/12pit/labels/release%20blocker 标签。

## 选择议题

https://github.com/12src/12pit/labels/help%20wanted 标签表示欢迎社区贡献。开始前，请选择同时带有 https://github.com/12src/12pit/labels/confirmed 标签的未关闭议题。想从小改动入手，可以选择带有 https://github.com/12src/12pit/labels/good%20first%20issue 标签的议题。确认议题还未被认领，并按[贡献指南](CONTRIBUTING.md)参与。
