# Issues

Check existing issues before opening one. If an issue covers the same problem, add any useful details there.

## Open an Issue

For a bug, describe what you expected, what happened, and how to reproduce it. Include the mod version, your Minecraft setup, and relevant log excerpts if available. Remove personal information, such as account credentials, before sharing logs.

For a feature request or enhancement, describe the problem and desired outcome. Short examples help. Questions and early ideas are welcome.

## Triage

While investigating an issue, maintainers can add these labels: https://github.com/12src/12pit/labels/needs%20triage, https://github.com/12src/12pit/labels/needs%20info, or https://github.com/12src/12pit/labels/needs%20reproduction.

Use https://github.com/12src/12pit/labels/needs%20decision when work needs a product or technical decision, and https://github.com/12src/12pit/labels/discussion for discussions. Use https://github.com/12src/12pit/labels/question for questions. Use https://github.com/12src/12pit/labels/invalid for issues based on false assumptions or unrelated to the project.

Once a problem is reproducible or a request is accepted, add the https://github.com/12src/12pit/labels/confirmed label, then classify the issue by type, area, priority, and environment.

Most issues are closed as completed when one or more pull requests are merged. Some close after a question is answered or a discussion ends. Use these labels for other closure reasons: https://github.com/12src/12pit/labels/duplicate, https://github.com/12src/12pit/labels/cannot%20reproduce, https://github.com/12src/12pit/labels/upstream, or https://github.com/12src/12pit/labels/wontfix.

## Labels

Use https://github.com/12src/12pit/labels/feature or https://github.com/12src/12pit/labels/enhancement for new requests.

Use https://github.com/12src/12pit/labels/bug, https://github.com/12src/12pit/labels/crash, https://github.com/12src/12pit/labels/regression, https://github.com/12src/12pit/labels/compatibility, or https://github.com/12src/12pit/labels/performance for problems.

A change may use the https://github.com/12src/12pit/labels/breaking%20change label. Use https://github.com/12src/12pit/labels/documentation, https://github.com/12src/12pit/labels/refactor, https://github.com/12src/12pit/labels/chore, or https://github.com/12src/12pit/labels/clean for other work.

Domain labels show which parts of the project an issue affects: https://github.com/12src/12pit/labels/domain%3A%20CI, https://github.com/12src/12pit/labels/domain%3A%20build, https://github.com/12src/12pit/labels/domain%3A%20dependencies, https://github.com/12src/12pit/labels/domain%3A%20release, https://github.com/12src/12pit/labels/domain%3A%20testing, https://github.com/12src/12pit/labels/domain%3A%20architecture, https://github.com/12src/12pit/labels/domain%3A%20tooling, https://github.com/12src/12pit/labels/domain%3A%20localization, https://github.com/12src/12pit/labels/domain%3A%20licensing, https://github.com/12src/12pit/labels/domain%3A%20governance, and https://github.com/12src/12pit/labels/domain%3A%20UI%2FUX.

Priority labels show how urgently work is needed: https://github.com/12src/12pit/labels/priority%3A%20P0, https://github.com/12src/12pit/labels/priority%3A%20P1, https://github.com/12src/12pit/labels/priority%3A%20P2, and https://github.com/12src/12pit/labels/priority%3A%20P3.

Environment labels show where an issue occurs: https://github.com/12src/12pit/labels/env%3A%20Windows, https://github.com/12src/12pit/labels/env%3A%20Linux, https://github.com/12src/12pit/labels/env%3A%20macOS, https://github.com/12src/12pit/labels/env%3A%20mod%20conflict, and https://github.com/12src/12pit/labels/env%3A%20server-specific.

An issue can also be https://github.com/12src/12pit/labels/blocked or https://github.com/12src/12pit/labels/release%20blocker.

## Pick an Issue

The https://github.com/12src/12pit/labels/help%20wanted label means community contributions are welcome. Choose an open issue labeled https://github.com/12src/12pit/labels/confirmed to work on. For a small first contribution, look for the https://github.com/12src/12pit/labels/good%20first%20issue label. Check that it is unclaimed and follow the [contributing guide](CONTRIBUTING.md).
