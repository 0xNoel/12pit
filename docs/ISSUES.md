# Issues

Please do a search for existing issues before filing a new one. If there's already an issue open for your problem or idea, just add additional information there.

## File an Issue

For bugs, please include what you expected to happen, what actually happens, and steps to reproduce the problem. Please include your 12pit version, Minecraft version, mods used, and any relevant log output that you have. Log files should have identifying data scrubbed before being posted.

For features or enhancements, explain the problem that you would like to solve and how you think the new functionality should behave. Short example usages are helpful and even rough ideas are appreciated!

## Triage

In the process of investigating a newly filed issue, maintainers may add the https://github.com/12src/12pit/labels/needs%20triage, https://github.com/12src/12pit/labels/needs%20info, or https://github.com/12src/12pit/labels/needs%20reproduction label.

Issues that require a product or technical decision prior to development use the https://github.com/12src/12pit/labels/needs%20decision label. Open-ended discussions get the https://github.com/12src/12pit/labels/discussion label. Usage questions are https://github.com/12src/12pit/labels/question issues. If an issue is not related to the project at all or stems from a misunderstanding, it will be labeled as https://github.com/12src/12pit/labels/invalid.

Once a bug is reproduced or a request is accepted by maintainers, the https://github.com/12src/12pit/labels/confirmed label is added along with those for type, domain, priority, and environment.

Most issues are automatically closed when a pull request is merged, or manually when a question is answered or a discussion finishes. For issues that are closed without a code change, the following labels are added: https://github.com/12src/12pit/labels/duplicate, https://github.com/12src/12pit/labels/cannot%20reproduce, https://github.com/12src/12pit/labels/upstream, or https://github.com/12src/12pit/labels/wontfix.

## Labels

New requests are filed as either https://github.com/12src/12pit/labels/feature or https://github.com/12src/12pit/labels/enhancement. Problems are filed as one of: https://github.com/12src/12pit/labels/bug, https://github.com/12src/12pit/labels/crash, https://github.com/12src/12pit/labels/regression, https://github.com/12src/12pit/labels/compatibility, or https://github.com/12src/12pit/labels/performance.

Other work uses one of these: https://github.com/12src/12pit/labels/documentation, https://github.com/12src/12pit/labels/refactor, https://github.com/12src/12pit/labels/chore, or https://github.com/12src/12pit/labels/clean, while breaking changes get the https://github.com/12src/12pit/labels/breaking%20change label.

Labels for domain indicate the area of the project involved in the issue: https://github.com/12src/12pit/labels/domain%3A%20CI, https://github.com/12src/12pit/labels/domain%3A%20build, https://github.com/12src/12pit/labels/domain%3A%20dependencies, https://github.com/12src/12pit/labels/domain%3A%20release, https://github.com/12src/12pit/labels/domain%3A%20testing, https://github.com/12src/12pit/labels/domain%3A%20architecture, https://github.com/12src/12pit/labels/domain%3A%20tooling, https://github.com/12src/12pit/labels/domain%3A%20localization, https://github.com/12src/12pit/labels/domain%3A%20licensing, https://github.com/12src/12pit/labels/domain%3A%20governance, or https://github.com/12src/12pit/labels/domain%3A%20UI%2FUX.

Priority tracking: https://github.com/12src/12pit/labels/priority%3A%20P0, https://github.com/12src/12pit/labels/priority%3A%20P1, https://github.com/12src/12pit/labels/priority%3A%20P2, and https://github.com/12src/12pit/labels/priority%3A%20P3. Environment specific issues use one of: https://github.com/12src/12pit/labels/env%3A%20Windows, https://github.com/12src/12pit/labels/env%3A%20Linux, https://github.com/12src/12pit/labels/env%3A%20macOS, https://github.com/12src/12pit/labels/env%3A%20mod%20conflict, or https://github.com/12src/12pit/labels/env%3A%20server-specific. Issues can also be labeled https://github.com/12src/12pit/labels/blocked or https://github.com/12src/12pit/labels/release%20blocker.

## Pick an Issue

Issues that are labeled as https://github.com/12src/12pit/labels/help%20wanted or https://github.com/12src/12pit/labels/good%20first%20issue and https://github.com/12src/12pit/labels/confirmed are available for community contribution. Make sure the issue hasn't been claimed first and refer to the [contributing guide](CONTRIBUTING.md).
